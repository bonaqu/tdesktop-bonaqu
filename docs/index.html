Bonaqu Desktop

Telegram Desktop WEB Proxy preview by bonaqu

Bonaqu Desktop is an open-source experimental build based on current Telegram Desktop development sources, focused on Windows x64 and the new WEB Proxy transport.

The current baseline is Telegram Desktop 7.1.1. Development builds temporarily use Telegram Desktop's official TDESKTOP_API_TEST=ON mode because Telegram API Development Tools is currently failing to create the maintainer's first API application.

This is an unofficial third-party fork and is not affiliated with or endorsed by Telegram.
