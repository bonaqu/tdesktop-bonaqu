Bonaqu Desktop

Personal Telegram Desktop fork by bonaqu

Bonaqu Desktop is an open-source personal build based on Telegram Desktop, maintained for testing and experimenting with current desktop features, including the new WEB Proxy transport.

The project follows the upstream Telegram Desktop source and licensing terms. It is an unofficial fork and is not affiliated with or endorsed by Telegram.
